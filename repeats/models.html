Model comparison on 200 human proteins

McWhite Lab, Department of Molecular and Cellular Biology, University of Arizona

Four language models read the same 200 blinded human proteins with the same prompt and no tools: Gemini Carbon, Gemini Neon, Claude Fable 5.2 and Claude Opus 5.5. Half of the proteins have a disordered or mixed repeat array in the Carbon screen; the other half, matched for length, have none.?The Carbon calls come from the full human screen and define the two halves, so Carbon agrees with the set by construction. The Known group (repeats recorded in ELM or UniProt, or cited in the literature) is a reference outside any model.

    Method

    1. Set. 100 proteins up to 2,600 aa sampled from those with a disordered or mixed repeat array in the Carbon screen, each paired with a protein of similar length with no repeat array. All 200 get new shuffled IDs.
    2. Reading. Each model gets the screen's prompt, four sequences per prompt, and reads with no code, tools or search.?The Claude models ran in Claude Code: each prompt went to a separate subagent with no tool access, and the coordinating session only batched sequences and checked quotes. Neither Claude model could see the other runs.
    3. Locating copies. A script finds each quoted copy in the sequence; every copy in all four runs was found.
    4. Comparison. Arrays from two models match when at least half of the residues of the smaller one overlap.
